Como Funciona?

O Elasticsearch organiza dados de forma otimizada para busca por texto completo.

Índices (Indices)

Pense em um índice como um banco de dados otimizado para busca. Ele armazena "Documentos" relacionados.

Documentos JSON

Cada entrada é um documento JSON. Flexível, legível e perfeito para dados complexos e não estruturados.

Natureza Distribuída

Os dados são divididos em "shards"[cite: 165], permitindo escalabilidade horizontal e alta disponibilidade.

Construído sobre o Apache Lucene

O poder central do Elasticsearch vem do Apache Lucene, a biblioteca de busca mais robusta do mundo, que ele abstrai e otimiza para um ambiente distribuído.
